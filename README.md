# 🦠 Corona‑Tweet

## 📘 Project Overview
This project performs **sentiment analysis of COVID‑19 vaccine tweets** using **machine learning techniques**.  
It aims to classify public opinions on vaccines as *positive*, *negative*, or *neutral* based on tweet content.

## 🎯 Objectives
- Collect and preprocess tweets related to COVID‑19 vaccines.  
- Apply text‑cleaning and tokenization techniques.  
- Use machine learning models (e.g., Naive Bayes, Logistic Regression, or SVM) to analyze sentiment.  
- Visualize sentiment trends and insights.

## 🧰 Technologies Used
- **Python 3.x**
- **Libraries:**  
  - `pandas` – data manipulation  
  - `numpy` – numerical operations  
  - `matplotlib` / `seaborn` – visualization  
  - `scikit‑learn` – machine learning models  
  - `nltk` / `textblob` – natural language processing
